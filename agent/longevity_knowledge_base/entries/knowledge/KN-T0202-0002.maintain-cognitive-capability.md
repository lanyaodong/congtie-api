# 保持认知能力

## 1. One-line Summary

保持认知能力，是尽可能长期保有理解信息、学习、记忆、集中注意力、规划和作出日常决定所需的综合能力。

## 2. User-facing Explanation

**范围说明：本条专门讨论认知能力。身体能力是长期能力保持的另一重要维度，在姊妹条目 `KN-T0202-0001《保持身体能力》` 中单独说明。**

认知能力不是一个单一分数。它包含多个彼此关联但不完全相同的维度，例如：

- 记忆；
- 注意力；
- 执行功能，包括计划多步骤任务、抑制控制（例如控制冲动反应和屏蔽无关信息），以及在不同任务之间灵活切换；
- 信息处理速度；
- 学习能力；
- 判断和决策；
- 语言与空间处理等其他功能。

随着年龄增长，一些认知过程可能发生变化。例如，处理速度或从记忆中提取信息可能变慢，但变化方式和程度存在明显个体差异；经验、知识和部分能力也可能相对稳定。正常老化中的变化不等同于轻度认知障碍，更不等同于痴呆。轻度认知障碍（MCI）通常指记忆或其他思维问题超过同龄人通常预期，但日常独立生活能力尚未像痴呆那样受到明显破坏；并不是所有 MCI 都会发展为痴呆。

反过来，也不能把所有变化都解释为“正常变老”。如果变化持续、明显，影响工作、财务管理、用药管理、出行或其他日常功能，专业评估可能更合适。Congtie 可以帮助用户整理时间线、例子和问题，但不能判断这些变化属于正常老化还是疾病。

主观感受和认知测试都需要上下文。听力和视力变化可能影响交流、认知测试表现和社会参与，因此在判断“认知变差”之前，也需要考虑感官因素。抑郁、焦虑、睡眠不足、某些药物影响等，也可能表现为注意力下降、自觉记忆变差——研究语境中常见“主观记忆抱怨”（memory complaints / subjective memory complaints）这样的表述——或决策困难。这些表现并不自动意味着神经退行性疾病，需要结合完整背景进行专业区分。一次测试或一个应用分数不能单独形成诊断，也不能精确计算未来认知风险。

既不应因为轻微健忘就陷入痴呆恐慌，也不应把持续、明显影响日常生活的认知变化简单归因于“正常老化”。

## 3. Key Points

- 认知能力包含记忆、注意力、执行功能、处理速度、学习和决策等多个维度。
- 正常认知老化具有个体差异，不等同于轻度认知障碍或痴呆。
- 不能把所有变化病理化，也不能把所有明显变化都视为正常。
- 主观感受和单次测试都需要时间、功能影响和其他上下文。
- 听力、视力、睡眠、情绪和药物等因素都可能影响认知表现，需要结合背景理解。
- 认知健康的一般人群证据不能直接生成个人风险分数。
- 本条不提供诊断、治疗或个性化认知训练方案。

### Quick Filter / 快速辨识

接触“认知健康评估”“脑力训练”或认知改善服务时，先核查：①是否区分正常年龄相关变化、MCI 和痴呆等不同概念；②是否承认主观感受和单次测试会受到睡眠、压力、药物、情绪、听力或视力等因素影响；③是否在推荐具体训练、补剂或治疗前提示持续、明显影响日常功能的变化需要专业评估。如果这些信息缺失，应进一步核查。

## 4. Evidence and Source Notes

1. WHO ICOPE 老年人整合照护指南提供认知、感官与心理健康支持的一般专业背景，但不用于个人风险计算。
2. 正常认知老化的同行评议综述支持多认知域、个体差异以及正常老化不等同于痴呆的区分。
3. NIA 认知健康和 MCI 教育资料支持多因素背景、MCI 的功能边界以及并非所有 MCI 都会进展为痴呆。
4. NIA 感官资料支持听力、视力等变化与认知表现和社会参与之间需要结合背景理解，但不证明某种干预对所有人都改善认知。
5. 中国国家卫生健康委员会 2024 健康素养资料支持识别老年期痴呆的一般公众教育语境，不作为诊断指南。

本条采用 `E3 / general_consensus`。它解释一般概念和观察性背景，不把人群资料转化为个人诊断、预测或治疗建议。

## 5. Safety Boundary

本条目不得用于：

- 诊断轻度认知障碍、痴呆、抑郁或其他疾病；
- 计算个人认知衰退或痴呆风险；
- 根据一次测试、主观感受或年龄作出医学结论；
- 保证某项活动或干预可以预防认知下降；
- 仅凭本条生成个性化训练、治疗、用药或补剂方案。

未来如提供个性化认知支持，需要结合完整健康背景、功能变化、适用人群、证据、权限和安全条件，并通过独立产品治理。
