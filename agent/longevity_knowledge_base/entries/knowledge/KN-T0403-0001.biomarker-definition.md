# 什么是生物标志物

## 1. One-line Summary

生物标志物是被测量、用于指示生物过程、疾病过程或对暴露与干预反应的特征；它是信息，不是自动成立的诊断、结论或行动指令。

## 2. 生物标志物是什么

FDA–NIH BEST Resource 将 biomarker 定义为一种经过测量的特征，用于指示正常生物过程、疾病过程，或对暴露与干预产生的反应。这里有两个关键词：

1. **经过测量**：需要明确测量对象、样本或信号、方法、单位和时间；
2. **用于指示**：它提供与某个问题相关的信息，但不自动回答全部临床问题。

血液或其他体液中的实验室分析物、组织学或影像量化特征，以及客观生理特征，都可能在特定 Context of Use 下成为 biomarker。功能或表现测量、用户报告和经验证问卷通常应作为独立的信息类型或 Clinical Outcome Assessment 治理，不能仅因为“经过验证”就自动称为 biomarker；只有真正符合 biomarker 定义、具体使用情境和证据要求时，才适合这样分类。

BEST 区分 biomarker 与“一个人如何感受、发挥功能或生存”的临床结局。用户自述、功能表现任务和验证量表可以是重要健康信息，但不自动成为 biomarker。

设备传感器采集的客观生理信号，在明确 Context of Use 和验证下可能成为 biomarker；设备 readiness、recovery、Stress Score 或 body battery 等算法推断结果，不会因为是健康数据就自动成为 biomarker。具体设备数据性质参见 `KN-T0408-0001`。

某项信息来自实验室、体检或设备，并不意味着它在所有用途下都是 biomarker。是否属于 biomarker，取决于 measured characteristic、Context of Use、intended use 和相应证据，而不是只看检测场所或项目名称。

## 3. Biomarker 的角色与 intended use

同一项测量在不同研究或应用中可能承担不同角色。BEST 记录的角色包括：

- susceptibility/risk biomarker / 易感性或风险生物标志物：与未来发生某种结果的易感性或风险相关；
- diagnostic biomarker / 诊断性生物标志物：用于发现或确认某种疾病或状态；
- monitoring biomarker / 监测性生物标志物：用于连续或重复评估状态变化；
- prognostic biomarker / 预后性生物标志物：在已有疾病或状态下，与未来临床事件或进程相关；
- predictive biomarker / 预测性生物标志物：与某项干预后出现特定效果的可能性相关；
- pharmacodynamic/response biomarker / 药效学或反应生物标志物：显示暴露或干预后发生了生物反应；
- safety biomarker / 安全性生物标志物：与暴露或干预可能产生的毒性或安全问题相关。

角色必须与具体 Context of Use（COU）和 intended use 绑定。某项 biomarker 在一项研究中用于 monitoring，不代表它在另一个人群、设备、方法或场景中也能用于 diagnosis 或 treatment selection。

“筛查”是一个人群、流程和临床目的相关的使用情境，不是 BEST 单列的 biomarker role。用于筛查的检测还需要独立评价目标人群、阈值、假阳性与假阴性、后续路径、获益、风险和监管要求。

BEST 还定义 multicomponent biomarker，即按照预先规定方式组合两个或以上 biomarker 的复合项目。它描述组合形式，不是第八个 intended-use role；组合后的项目仍需针对具体 Context of Use 独立评价。

## 4. 生物标志物不等于什么

- **不等于全部健康信息。** 用户自述、行为记录、社会环境、临床记录和设备推断需要各自的数据类型与治理。
- **不等于诊断。** 一个数字异常通常不能独立证明某种疾病。
- **不等于临床效用。** 测得准、有统计关联，不等于使用它一定能改善个人决策或健康结果。
- **不等于个性化方案。** 一项 biomarker 不能单独决定测什么、做什么、用什么药或何时干预。
- **不等于固定归属。** 很多 biomarker 与多个身体系统有关，产品展示分组不应伪装成唯一生物学归属。

### 三类验证与效用

**分析有效性 / Analytical Validation**：是否能够可靠、重复地测量目标对象。

**临床有效性 / Clinical Validation**：结果是否能够反映、识别或预测 intended concept。

**临床效用 / Clinical Utility**：在具体使用情境中，使用结果是否改善决策或健康结果。

三者不能合并为一个判断：`measurable != clinically valid != clinically useful`。

## 5. 与 Biomarker and Measurement Registry 的关系

Congtie 的 Biomarker and Measurement Registry（生物标志物与测量项目注册表）用于记录公共、可复用的项目定义，例如名称、别名、信息类型、单位、样本、方法、用途、局限、证据和允许的 Agent 使用范围。

Registry item 是“这个项目是什么”的公共定义；用户 observation 是“这个用户在什么时间、由什么来源、以什么方法得到什么结果”的个人记录。两者必须连接，但不能混为一谈。

Registry 可以收录 biomarker，也可以收录不是 biomarker 的测量项目。是否属于 biomarker，需要根据 measured characteristic、用途和证据判断，不能仅凭名称或产品标签决定。

## 6. 如何补全一个 biomarker 的最少上下文

在用户希望理解某项结果、且现有上下文不足时，Agent 可以优先复用 User Health Information Library 已有信息，只补问最少的关键缺口：

- 这项结果的原始名称、数值和单位是什么？
- 检测或测量日期是什么时候？
- 来源是哪个实验室、设备或报告？
- 样本和方法是否已知，原始参考区间或实验室报告标注的参考信息是什么？不同实验室、方法和参考人群的区间可能不同。
- 用户希望理解的是定义、趋势、用途，还是报告中的异常提示？

用户可以跳过任何问题。补问用于避免误读，不代表已建立运行时问诊、提醒或自动检测流程。

## 7. Evidence Boundary

本条的 `E1` 仅适用于 FDA–NIH BEST Full Resource 与 Glossary 支持的 biomarker 通用定义、COA/COU 术语、角色分类、multicomponent biomarker 和基础用途边界。它不把具体 biomarker 的分析有效性、临床有效性、临床效用或个人适用性自动升级为 E1。

具体 biomarker 仍需按具体 claim 核验：测量方法是否可靠、研究对象是否适用、阈值如何形成、能否改变决策、是否改善结果，以及监管和专业边界是什么。

## 8. Safety Boundary

遇到具体个人结果时，不得只依据本条：

- 作出疾病诊断或排除诊断；
- 计算个人风险、预期寿命或身体系统评分；
- 忽略实验室、方法、单位、参考信息和临床上下文；
- 自动生成检测、治疗、用药、补剂或个性化长寿方案。

如果报告标注 critical/alert value，或用户同时出现急性、严重、快速进展的症状，应优先遵循报告和专业医疗指引，不应等待一般知识解释替代及时处置。

Biomarker 的定义或 BEST 角色分类不能作为对功能医学检测、生物年龄测试、再生医学产品或其他具体检测与干预的背书。遇到具体项目时，应独立核查分析有效性、临床有效性、临床效用、Context of Use、监管状态和个人适用性。

## 9. Agent Usage Notes

在 Founder 批准并通过独立发布流程后，Agent 可使用本条解释 biomarker 的定义、角色和限制，或帮助用户整理一项测量所需的最少上下文。

Agent 必须把定义权威、具体测量证据、用户 observation 和行动权限分开。主动补全上下文时，应优先使用已授权的 User Health Information Library，不重复询问已有信息；一次优先提出 1–3 个可能改变当前判断的关键问题，并说明原因。用户可以跳过，未回复不等于正常或已完成。不得因为某项检测被营销为 biomarker，就自动把它视为已验证、有临床效用或值得购买；也不得把 Registry 收录理解为 Congtie 推荐该检测。本条不实现自动问诊、reminder、scheduler 或 runtime。
