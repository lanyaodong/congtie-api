# 保持身体能力

## 1. One-line Summary

保持身体能力，是尽可能长期保有完成日常活动、应对身体任务和维持独立生活所需的综合能力。

## 2. User-facing Explanation

**范围说明：本条专门讨论身体能力。认知能力是长期能力保持的另一重要维度，在姊妹条目 `KN-T0202-0002《保持认知能力》` 中单独说明。**

身体能力不是一个单独数字。它描述一个人在真实生活中完成身体任务的综合能力，例如起身、行走、搬拿物品、上下楼、保持平衡、持续活动，以及在活动后恢复。

常见维度包括：

- 力量；
- 肌肉量、肌肉质量与实际功能；
- 活动度和关节可用范围；
- 平衡与稳定；
- 心肺适能和耐力；
- 爆发力，即较短时间内快速产生力量的能力，例如快速起身、跨越障碍，或身体突然失去平衡时及时调整；
- 恢复能力，例如较大活动量后的疲劳消退、连续几天活动后的体能储备回升，以及面对生理压力后恢复稳定状态的能力；
- 日常功能和独立生活能力。

肌肉量描述有多少肌肉组织；肌肉质量关注肌肉组织产生功能的效率和组织特征；实际功能则看人能否完成起身、行走、爬楼、负重等真实任务。三者相关，但不能互相替代。

其他维度同样不能互相替代。握力、步行速度、起立测试、设备估算的 VO₂max 或某次锻炼表现都可能提供局部信息，却不能单独定义一个人的完整身体能力。测量结果还会受到方法、设备、当日状态、疼痛、疾病和熟悉程度影响。这里的恢复能力也不等同于伤病后的临床康复方案。

人群研究发现，一些身体能力测量与后续健康结局存在关联，但关联不是个人命运，也不能说明改善某一个数字一定会延长寿命。保持身体能力的价值首先体现在功能、参与生活和独立性，而不是追求一个万能分数。

在中国老年健康语境下，肌肉减少、平衡下降和跌倒是身体能力维护中值得特别关注的问题。长期目标并不是追求极限运动表现，而是尽可能保持力量、移动、平衡和日常独立生活能力。“肌少症”属于需要专业判断的医学状态，不能仅凭本条、自我测试或设备分数自行诊断。

本条只解释概念。具体训练、伤病恢复和疾病相关限制需要结合个人情况与专业判断。

## 3. Key Points

- 身体能力是多维综合能力，不是单一体能数字。
- 力量、活动度、平衡、心肺适能、耐力、爆发力、恢复和日常功能都可能重要。
- 肌肉量不等于肌肉功能，设备估算也不等于专业评估。
- 人群层面的关联不能直接预测个人寿命或疾病风险。
- 保持身体能力关注长期功能和独立性，不是追求完美分数。
- 本条不提供个性化训练或康复方案。
- 疼痛、反复跌倒、明显或快速的功能下降，以及疾病状态下的身体能力变化，需要结合专业评估，不能仅凭自我测试、穿戴设备或单一指标判断。

### Quick Filter / 快速辨识

接触“身体能力评估”或“体能优化”内容时，先核查：①是否承认身体能力是多维的，而不是只凭一个设备分数下结论；②是否区分人群层面的统计关联与个人寿命或疾病风险预测；③是否在涉及疼痛、伤病、反复跌倒或明显功能下降时提示专业评估。如果这些信息缺失，应进一步核查，而不是仅凭一个“体能分数”采取行动。

## 4. Evidence and Source Notes

1. WHO 健康老龄化报告提供功能能力、内在能力和环境的总体框架。
2. 同行评议综述/Meta 分析支持多类身体能力测量与后续健康结局存在人群层面关联，但不能据此推断个人因果或寿命。
3. NIA 专业教育资料支持身体活动与日常功能、独立生活的一般关系。
4. 中国国家卫生健康委员会 2024 健康素养及其释义支持老年跌倒预防以及平衡、肌肉力量和耐力锻炼的公众教育语境，不支持用户自行诊断肌少症。

本条采用 `E3 / general_consensus`，用于表达多维身体能力概念和观察性关联，不把它升级为个人临床预测或训练处方。

## 5. Safety Boundary

本条目不得用于：

- 建立身体能力总分、系统评分或疾病风险分数；
- 根据单一测量预测个人寿命或健康结局；
- 仅凭本条生成个性化训练负荷、频率、动作或进阶计划；
- 制定伤病、术后或疾病相关康复方案；
- 替代专业运动、康复或临床评估。

未来版本如提供个性化训练支持，需要结合当前健康背景、目标、伤病或疾病情况、安全筛查、证据和用户授权，并通过独立产品治理。
