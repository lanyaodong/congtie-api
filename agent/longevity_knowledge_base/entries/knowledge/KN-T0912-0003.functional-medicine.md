# 功能医学是什么

## 1. One-line Summary

功能医学目前更适合被理解为一种定义和实践较为异质、不同机构使用方式并不完全一致的实践模式；“功能医学”这个名称本身不是一个证据等级。

## 2. What It Is / 是什么

功能医学（Functional Medicine）没有一个在所有机构和专业体系中完全一致的实践定义。Institute for Functional Medicine（IFM）把它描述为关注疾病或失衡的根本原因，并结合遗传、环境、生活方式和个体差异来组织照护的框架。

这是 IFM 对自身实践模式的定义，适合用于说明支持者怎样描述功能医学，不应直接当成整体疗效已经得到证明的结论。

## 3. Core Principles or Typical Scope / 核心关注与典型范围

功能医学实践常强调：

- 从多因素和系统关联理解健康问题；
- 关注遗传、环境、饮食、生活方式和社会背景；
- 收集较多个人历史和上下文；
- 强调个体差异和长期关系；
- 尝试寻找被称为“root causes”的上游因素。

不同机构可能在“root cause”的定义、检测选择、干预方式、人员资质和与常规医疗的关系上有很大差异。因此，不能只看标签判断实际服务内容。

## 4. Relationship to Longevity and Healthspan / 与长寿和健康寿命的关系

主动延寿用户容易接触功能医学，是因为它常讨论长期健康、生活方式、代谢背景、环境暴露、个体差异和多种检测。这些主题与健康寿命有关，但相关性不等于某套检测组合或干预方案已经被证实能延长寿命。

一个与健康寿命有关的概念，也不能自动转化为对个人的检测、补剂或治疗建议。

## 5. Relationship to Other Medical Fields / 与其他医学领域的关系

- **常规医学**依据明确的专业训练、诊断和治疗标准开展医疗服务；功能医学实践可能由常规医疗专业人员提供，也可能混合其他方法。
- **整合医学**关注常规医疗与互补方法的协调使用；功能医学在一些语境中与其重叠，但两者不是固定同义词。
- **生活方式医学**拥有较清晰的专业实践框架和行为改变重点；功能医学也常将生活方式纳入实践，同时可能包含更广泛的检测和干预。两者存在交集，但关注重点、术语边界和具体实践并不相同，因此不能互相替代，也不能借用对方的证据成熟度。

美国 NIH 下属 NCCIH 在解释 complementary、alternative 和 integrative health 等术语时提到 functional medicine，并指出这个词有时指接近 integrative health 的概念，也可能指更接近 naturopathy 的实践；NCCIH 同时将 functional medicine 作为部分“不容易整齐分类”的 complementary approaches 示例之一。这反映出该术语和实践边界并不统一，并不代表 NCCIH 对其中所有具体实践作出了统一肯定或否定。

## 6. Field Maturity and Recognition / 领域成熟度与认可情况

功能医学已经存在专业组织、培训、服务模式和部分同行评议研究，但不同机构的定义、服务内容和证据质量差异明显。它更适合被描述为“异质、定义不完全统一的实践模式”，不宜写成全球标准一致的专科。

在中国，功能医学已经出现在专业培训、健康管理以及部分医疗健康服务场景中。FMC 自述其为 2014 年创立的功能医学传播与培训平台，这可作为中国专业培训生态正在形成的信号，但不是政府认可或临床疗效证据。“功能医学”名称本身不能替代法定医疗资质、人员执业范围或具体项目的合规要求。用户仍应分别核查实际服务机构、具体提供者，以及每项检测和干预的证据与监管状态。

Congtie 对这个标签既不整体背书，也不整体否定。判断重点应回到具体 claim 和具体 intervention。

## 7. Evidence Boundary / 证据边界

2019 年一项回顾性队列研究观察到，在功能医学中心接受服务的患者与常规家庭医疗患者，在部分随访时点的患者报告身体健康变化存在差异。由于研究采用非随机设计，并可能受到患者选择、残余混杂、医疗场景差异及随访缺失等因素影响，这项研究能够说明“观察到了关联”，但不能证明功能医学整体实践模式具有因果疗效。针对功能医学整体实践模式的有效性，不能由上述观察性研究单独确立；需要结合后续独立、前瞻性和随机研究持续评价。

本条 `E5` 用于表示 Functional Medicine 作为异质实践标签或框架的定义和成熟度，不代表所有被归入 Functional Medicine 的检测、补剂、饮食、药物或 protocol 都属于 E5；每个具体 intervention 必须独立评价。

如果功能医学服务涉及以下内容，需要分别重新评价：

```text
lab test
hormone test
microbiome test
supplement
diet
hormone therapy
drug
detox
IV therapy
microbiome intervention
```

每一项都应独立检查 claim、evidence、safety、regulatory status 和 actionability。

## 8. 这个医学名称本身不能告诉你什么？

功能医学标签不能证明其中某个检测、补剂、药物、饮食、激素方案或其他 intervention 有效、安全或适合某个用户。

这个标签也不能自动说明服务应被推荐、拒绝、降级或背书。

## 9. User-facing Practical Interpretation / 用户如何理解和使用这个概念

面对功能医学内容或服务，可以把问题拆开：

- 这是机构对自身模式的描述，还是独立证据？
- 具体要做什么检测或干预？
- 每个主张的证据等级是什么？
- 有哪些安全、费用、隐私和监管问题？
- 是否排斥必要医疗或制造过度检测？
- 提供服务的人员是否具备所在国家或地区与实际服务内容相匹配的医疗或健康专业资质、执业范围或其他必要资格？

评价具体内容，比争论标签整体“好”或“坏”更可靠。

“排毒（detox）”是高度模糊的营销和健康术语，其具体含义必须拆解。医学上针对明确中毒或特定适应证的治疗，与泛化的商业“排毒方案”不是同一概念；不能因词语相同就整体背书或整体否定。

### Quick Filter / 快速辨识

接触功能医学服务时，先核查机构和实际服务人员的身份与资质是否清楚；“root cause”等框架主张是否与具体检测或干预的证据分开表达；是否说明与必要的常规医疗如何协作。如果这些信息含糊，应进一步核查，而不是仅凭“功能医学”标签采取行动。

## 10. Safety Boundary

本条仅用于概念和证据边界教育。不得据此推荐或否定任何具体检测、补剂、药物、激素、排毒或静脉输注方案；不得生成诊断、治疗、剂量、风险评分、系统评分、个性化补剂方案或其他医疗干预。

## 11. Agent Usage Notes

在 Founder 批准并通过独立发布流程后，Agent 可分别说明 IFM 自我定义、NCCIH 独立语境、功能医学实践异质性和观察性研究限制。

Agent 不得把自我定义当疗效证据，不得把观察性关联写成因果证明，也不得因标签自动推荐、否定或生成任何具体 protocol。

Agent 不得把 Functional Medicine 的“root causes”“systems view”等框架语言作为对 Longevity Medicine 或 Lifestyle Medicine 的替代、质疑或背书依据，也不得混用 Functional Medicine 与 Lifestyle Medicine。

用户询问食物不耐受 IgG、“肾上腺疲劳”评估、重金属检测、“排毒”方案、静脉输注、激素、补剂或其他具体检测和干预时，Agent 必须分别核查项目本身的 claim、证据、安全性和监管状态，不得仅引用 Functional Medicine 概念框架进行泛化支持。
