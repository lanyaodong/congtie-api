# 睡眠基础

## 1. One-line Summary

睡眠不是只有“睡了几小时”一个数字；长期理解睡眠，需要同时关注时长、时间、规律、连续性、主观感受和白天功能。

## 2. 睡眠为什么值得长期关注

睡眠是基本的生理过程，也是日常长寿实践的重要生活方式基础。它与白天警觉、情绪、学习记忆、代谢、心血管和免疫等多个方面有关。

这不意味着一次没睡好就会导致某种疾病，也不意味着把某个设备分数提高就能证明长期健康获益。更有价值的做法是观察多个维度在一段时间内的模式，并把主观感受、生活情境和数据来源放在一起理解。

## 3. 睡眠是多维度的

### 时长 / Duration

睡眠时长需要先说明口径：

- **主要睡眠时长 / Main Sleep Duration**：主要睡眠时段内实际或估算睡着的时间；
- **24 小时总睡眠 / Total 24-Hour Sleep**：24 小时内主要睡眠和小睡的总和；
- **卧床时间 / Time in Bed**：从上床到离床的时间；
- **睡眠机会 / Sleep Opportunity**：现实生活中为睡眠预留的时间。

四者不自动相等。小睡是否适合取决于年龄、时点、时长、轮班和个人情境，本条不作统一推荐。

专业共识提供以下人群层面的一般参考：

| 年龄 | 一般睡眠时长参考 |
|---|---|
| 4–12 个月 | 每 24 小时 12–16 小时，含小睡 |
| 1–2 岁 | 每 24 小时 11–14 小时，含小睡 |
| 3–5 岁 | 每 24 小时 10–13 小时，含小睡 |
| 6–12 岁 | 每 24 小时 9–12 小时 |
| 13–18 岁 | 每 24 小时 8–10 小时 |
| 健康成人 | 通常应规律地每晚至少睡眠 7 小时 |

另一套常用的 National Sleep Foundation 专家共识将 18–64 岁成年人的适宜睡眠范围概括为每晚 7–9 小时，将 65 岁及以上人群概括为 7–8 小时。这与 AASM/SRS 的“健康成人通常应规律地每晚睡眠至少 7 小时”是两种不同的专业共识表达，均属于人群参考，不是个人精确处方。

4 个月以下婴儿个体差异较大，AASM 未给出统一时长推荐。以上是人群参考，不是个人处方；也不能因为年龄增加就自动假设老年人只需要很少睡眠。疾病、妊娠、恢复、轮班、分段睡眠和照护责任等情境需要单独考虑。

### 时间 / Timing

入睡、醒来和主要睡眠发生在什么时间。时长相同但时间不同，可能对应不同的昼夜节律和生活情境。

### 昼夜节律时型 / Chronotype

昼夜节律时型在用户侧也可称睡眠时型，常见描述包括晨型、中间型和晚型，反映一个人偏好的睡眠—觉醒时间。它不是疾病或人格诊断，会受到年龄、光照、社会作息和环境影响。个人偏好与工作或学校时间不匹配时可能产生社会时差；晚型不等于可以长期少睡。本条不展开光疗或昼夜节律睡眠障碍治疗。

### 规律 / Regularity

每天的入睡、醒来和时长是否相对稳定。规律不是要求每天完全相同，而是观察是否存在长期、明显和与功能相关的波动。

### 连续性 / Continuity

睡眠是否经常中断、长时间清醒，或难以重新入睡。设备估算的觉醒次数与用户实际感受、临床测量不一定一致。

### 主观感受与白天功能 / Subjective Experience and Daytime Function

用户是否觉得睡得恢复、醒后精神如何、白天是否过度困倦，以及睡眠是否影响工作、学习、情绪和安全。主观感受是重要个人依据，不是“低质量数据”，但它也不单独构成医学诊断。

### 睡眠障碍与安全边界 / Sleep Disorder Boundary

一般知识、主观记录和消费级设备都不能证明“没有睡眠障碍”，也不能用来排除失眠、睡眠呼吸暂停、昼夜节律睡眠障碍或其他临床问题。

## 4. 主观记录、设备和临床测量有什么区别

- **用户自述**：回答“我感觉如何、白天功能如何”，属于 personal context basis；主观感受是重要且不能被忽略的个人依据，但它与外部科学证据、设备测量和临床评估属于不同层级的信息，用户自述不会因为被记录就自动获得科学证据等级；
- **睡眠日记**：记录上床、入睡估计、醒来、夜间觉醒、咖啡因、酒精、锻炼和重要情境；
- **消费级设备**：通过传感器和算法估算睡眠时长、阶段、心率等，适合在明确限制下观察模式；
- **床伴或室友观察**：可能提供用户自己不知道的打鼾、呼吸暂停、喘醒、肢体活动、梦游或明显作息变化等线索；
- **临床测量**：例如 polysomnography（PSG）和专业评估，用于特定临床问题，不能由消费级设备直接替代。

这些信息可以互相补充，但不能互相替代。设备显示“睡得好”不一定解释用户持续疲劳；用户感觉差也不能仅凭一晚自述确定疾病。床伴或室友观察属于重要线索，不是诊断；涉及安全或持续异常时需要专业评估。

## 常见睡眠监测指标如何分类 / How to Classify Common Sleep Metrics

### 1. 时间与机会

- sleep opportunity / 睡眠机会；
- time in bed / 卧床时间；
- total sleep time / 总睡眠时间；
- main sleep duration / 主要睡眠时长；
- nap duration / 小睡时长。

### 2. 入睡与连续性

- sleep latency / 入睡潜伏期；
- WASO / 入睡后清醒时间；
- awakening count / 夜间觉醒次数；
- sleep efficiency / 睡眠效率。

睡眠效率通常按总睡眠时间除以卧床时间计算，但研究、睡眠日记、临床系统和消费设备可能采用不同的时间边界、分母或算法。不同来源的睡眠效率在未核对定义时不能直接比较。本条不提供统一“正常睡眠效率”阈值或个人治疗建议。

### 3. 时相与规律

- bedtime / 上床时间；
- sleep onset time / 入睡时间；
- wake time / 醒来时间；
- sleep midpoint / 睡眠中点；
- sleep regularity / 睡眠规律；
- social jetlag / 社会时差。

### 4. 睡眠结构

- light sleep / 浅睡；
- deep sleep / 深睡；
- REM sleep / 快速眼动睡眠；
- stage proportion / 睡眠阶段占比。

消费设备的睡眠阶段通常是算法估算，不能直接等同 PSG 阶段判定，也不宜过度解读单晚的小幅差异。

### 5. 睡眠期生理指标

- sleeping heart rate / 睡眠期心率；
- nocturnal HRV / 睡眠期或夜间 HRV；
- respiratory rate / 呼吸频率；
- SpO₂ / 血氧饱和度；
- skin temperature / 皮肤温度。

夜间 HRV 是自主神经活动相关的生理指标或设备估算指标，不是睡眠质量、恢复状态或压力的直接测量。解读时必须记录具体 HRV 指标、时间窗口、设备、伪差处理和算法版本，不能把所有“睡眠 HRV”归为同一个标准指标。

### 6. 用户报告指标

- subjective sleep quality / 主观睡眠质量；
- restoration feeling / 恢复感；
- daytime sleepiness / 白天困倦；
- daytime function / 白天功能。

这些属于 personal context basis，不会因为被记录就自动获得外部科学证据等级。

### 7. 综合评分

- sleep score / 睡眠评分；
- recovery score / 恢复评分；
- readiness score / 准备度评分。

综合评分通常是设备厂商自有算法根据多个输入形成的 inferred score。不同厂商的公式和权重不同，不能默认跨设备比较，也不能当作诊断或唯一睡眠目标。

### 信息类型边界

- sleep efficiency 是 derived sleep metric；
- sleep score 是 proprietary derived score/index；
- nocturnal HRV 根据来源可属于 physiological measurement 或 device-estimated metric；
- sleep stage 根据来源可属于 clinical classification 或 device estimate；
- subjective sleep quality 是 user-reported state；
- SpO₂、respiratory rate 和 heart rate 根据设备和方法可属于 physiological measurement 或 estimate。

这些信息不能全部统一称为 biomarkers。只有在明确 Context of Use、测量定义和验证成立时，才讨论某项测量是否承担 biomarker role。

## 5. 影响睡眠的主要上下文

这些因素用于帮助理解情境，不是固定优化处方：

### 昼夜节律与光照 / Circadian and Light

- 白天和晨间光照；
- 晚间人工光，屏幕是夜间光照来源之一；
- 轮班、旅行和时差。

### 环境 / Environment

- 光线、噪声、热环境和个人热舒适；
- 床垫、枕头和寝具舒适度；
- 床伴、室友、儿童、宠物和照护责任。

本条不给所有人设定统一卧室温度、唯一最佳床垫软硬度或具体产品推荐。

### 物质与行为 / Substances and Behaviors

- 咖啡因的类型、大致剂量和摄入时间；
- 酒精的类型、总量和结束时间；
- 进食时间、进食量和反流背景；
- 锻炼类型、强度和结束时间；
- 尼古丁、药物和补剂。

这些变量的关系受剂量、时间和个人情境影响。本条不声称所有晚间锻炼都会损害睡眠，不按酒种直接判断影响大小，不从一次晚餐证明因果，也不给所有人设定统一咖啡因截止时间。

### 健康与心理社会情境 / Health and Psychosocial Context

- 疼痛、急性疾病和药物变化；
- 压力与情绪、工作负荷；
- 轮班、旅行、育儿和照护。

## 6. 如何开始记录，而不把睡眠变成压力来源

一般情况下，可以先选择少量、可持续的信息：

- 大致入睡和醒来时间；
- 主观睡眠质量或恢复感；
- 白天困倦和功能影响；
- 是否存在明显夜间觉醒；
- 影响当晚的特殊事件。

如果用户已经有设备数据，可保留设备、指标、时间窗口和版本，而不是只保存平台综合分数。记录的目的应是减少重要不确定性，不是追求每晚完美，也不是因小幅变化持续增加检测。

## 7. 最少上下文补全

当用户问“为什么昨晚睡差了”“为什么最近睡不好”或希望理解某个睡眠数字时，Agent 应先复用已有授权记录，并根据当前问题一次只选择 1–3 个高价值缺口。提问时应简短说明用途：这些信息用于比较当晚与平时的情境，不直接确定因果。

- 变化持续了多久，主要是时长、时间、觉醒、恢复感还是白天困倦？
- 信息来自用户感受、睡眠日记、消费级设备还是专业测量？
- 晚餐几点结束，是否明显比平时更晚或更多？
- 是否饮酒；如相关，酒种、大致数量和最后饮用时间是什么？酒种主要帮助估算乙醇量和饮用情境，不单独决定睡眠影响。
- 咖啡、茶、能量饮料或其他咖啡因来源的大致数量和最后摄入时间是什么？
- 锻炼类型、强度和结束时间是什么？
- 光线、噪声、温度、寝具，或床伴、室友、儿童、宠物等环境是否变化？
- 是否存在疼痛、急性疾病、药物变化、旅行、轮班、重要压力或情绪变化？
- 是否有呼吸停止或喘醒、危险性日间嗜睡、困倦驾驶或明显功能影响？

这些问题应保持中性，一次不应全部询问；询问酒精、进餐或锻炼只是在补充情境，不预设它们就是原因。用户可以跳过任何问题，未回复时也不得自动推断。本条不实现问诊、提醒、scheduler 或自动个性化睡眠方案。

## 8. 不要从单次事件直接推断因果

睡眠容易受到多种因素同时影响。一次晚餐、一次饮酒、一次锻炼、一次压力事件或一晚设备分数变化，只能形成需要继续观察的线索，不能单独证明因果。

观察长期模式时，应尽量保持记录定义一致，并注意工作日与周末、旅行、疾病、环境变化和设备算法更新等断点。必要时可在专业支持下判断是否需要进一步评估。

## 9. Evidence Boundary

本条的 `E1` 主要适用于专业组织支持的“睡眠对健康重要”“睡眠是多维度的”、年龄相关一般睡眠时长共识和一般安全教育。它不表示每个睡眠维度、每个设备指标或每项改善方法都拥有统一 E1 证据。

一般成人“规律获得每晚 7 小时或以上”、NSF 成人/老年人推荐范围和儿童每 24 小时参考都不是对所有用户的个性化处方。sleep efficiency、device sleep stage、nocturnal HRV、sleep score、SpO₂、wearable algorithms，以及咖啡因、酒精、锻炼、进食和环境等具体影响，应按各自 claim 使用相应来源和证据等级，不能因为出现在 E1 条目中就自动成为 E1。具体睡眠需求、症状评估、疾病诊断、治疗和作息调整需要结合个人情境及相应证据。

## 10. Quick Filter / 快速辨识

遇到睡眠建议或设备结论时，可以先核查：

1. 是否只看时长或单一分数，还是同时考虑规律、时间、主观感受和白天功能？
2. 数据来自自述、设备估算还是临床测量，三者是否被混为一谈？
3. 是否从一次事件直接声称因果？
4. 是否把一般人群建议直接变成精确个人处方？
5. 是否忽略呼吸异常、危险性困倦或持续功能影响等安全信号？

## 11. Product and Service Boundary

睡眠基础知识不能作为智能床垫、助眠补剂、褪黑素、白噪声设备、睡眠教练、课程或其他产品服务的背书。具体项目须独立核验证据、安全、监管和商业关系。未来 T07 可以在独立治理下提供商品或服务决策支持，本条不提供具体推荐。

## 12. Safety Boundary

Agent 不得：

- 根据设备睡眠阶段或单次分数诊断疾病；
- 仅凭一次晚睡、饮酒、进餐或锻炼推断确定因果；
- 为所有用户给出相同睡眠时长或固定作息；
- 用正常设备分数排除持续严重症状；
- 仅依据本条生成个性化睡眠治疗、药物、补剂或完整个性化睡眠方案。

出现反复呼吸停止或喘醒、危险性日间嗜睡、困倦驾驶、持续严重失眠、快速明显变化或持续影响日常功能时，应优先寻求专业评估。

## 13. Agent Usage Notes

在 Founder 批准并通过独立发布流程后，Agent 可使用本条解释多维睡眠健康、区分数据来源、帮助用户选择少量记录项，以及提出最少且中性的上下文问题。

Agent 应把一般证据、用户主观状态、床伴线索、设备估算和临床信息分开。不得将本条当作睡眠障碍诊断工具。本条本身不授权个性化睡眠治疗、用药或补剂方案；未来 Personalized Longevity Protocol 可以在用户授权、个人健康信息、证据、安全规则和产品治理下包含个性化睡眠行为、测量、行动和复测模块，睡眠疾病诊断与治疗仍需独立临床边界。

主动补全上下文时，Agent 应优先复用已授权的 User Health Information Library，不重复询问已有信息；一次优先提出 1–3 个可能改变当前解读的关键问题，并说明为什么需要。用户可以跳过，未回复不等于正常或信息已完成。本条不实现自动问诊、reminder、scheduler 或 runtime。

本条保持基础概览和指标地图：`KN-T0501-0002` 后续可深化睡眠时长、规律、主观质量、sleep latency、WASO、sleep efficiency、小睡和社会时差；`KN-T0408-0001` 治理设备估算、sleep score、sleep stage、HRV、SpO₂ 和算法版本；Biomarker and Measurement Registry 未来保存 item-level 定义、单位、算法、设备和 provenance。T05.07 后续可深化昼夜节律与光照；咖啡因、酒精、进食、锻炼时间和睡眠环境也可在独立条目中展开。

当前状态为 `human_review_pending`，不得进入 runtime 或 retrieval。

## 14. Founder / Reviewer Notes

Founder 建议重点审核：

- 多维睡眠结构是否自然、准确且适合中国用户；

- 酒精、咖啡因、进餐和锻炼补问是否中性；

- 专业升级信号是否足够清楚且不过度制造焦虑。
