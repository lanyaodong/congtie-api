# 如何理解基线、长期趋势、测量误差与生物波动

## 1. One-line Summary

一个数字发生变化，可能来自真实的长期变化、人体自身的生物波动、采集前条件或测量过程；理解它，需要先保护可比性，而不是把每次变化都当成健康变好或变坏。

## 2. 几类容易混淆的概念

### 个人基线 / Personal Baseline

个人基线是某个用户在相对稳定、条件可比较的一段时间内形成的参考背景。它通常需要多次可比较观察以及时间、方法和情境信息。

**第一次测量只是第一个观察点，不自动等于个人基线。** 如果第一次测量恰逢急性疾病、剧烈运动后、睡眠不足、脱水或其他特殊情境，它甚至可能不适合代表平常状态。

某项研究、临床任务或干预前预先规定的单次测量可以被称为该任务的 baseline，但不自动等于长期个人稳态基线。稳定个人基线通常需要在相对稳定、条件可比的情境下进行多次观察。

### 长期趋势 / Longitudinal Trend

长期趋势关注多个时间点在相对可比较条件下的方向、幅度和持续性。趋势不只是把点连成线；还要看单位、实验室或设备、方法、采集条件和数据缺失。

### 测量误差 / Measurement Error

测量误差是测量结果与真实值或参考量值之间的差异；实际工作中，真实值往往无法被完全知道。单位抄录、人工录入、四舍五入或未经验证的换算，也可能形成额外的数据错误。

### 测量不确定性 / Measurement Uncertainty

测量不确定性是依据现有信息，对可合理归属于测量值的离散程度或知识范围的表达。它描述对结果所知的边界，不是已经知道方向和大小的一个“误差值”。因此，**measurement error 不等于 measurement uncertainty**。

### 前分析影响 / Preanalytical Influences

前分析影响发生在检测分析之前或样本进入分析过程之前，包括：

- 禁食状态、采样时间和体位；
- 近期剧烈锻炼、急性疾病和饮酒；
- 药物或补剂的开始、停止或变化；
- 采样方式、储存、运输和稳定性；
- 适用时的止血带使用、溶血、脂血等样本状态。

前分析影响不一定是仪器或实验室分析错误；部分因素会真实改变采样时的生理状态或样本状态。

### 分析变异 / Analytical Variation

分析变异发生在实验室或设备的分析阶段，可能涉及 assay precision、校准、试剂、平台、仪器、实验室流程，以及设备或算法的重复性。前分析影响与分析变异都可能影响结果，但发生环节和改进方法不同。

### 生物波动 / Biological Variation

即使测量过程没有错误，人体指标也可能随时间发生真实的生理变化：

- **个体内生物变异 / Within-person biological variation**：在相对稳定状态下，指标围绕个人稳态设定点发生变化；
- **个体间生物变异 / Between-person biological variation**：不同人的稳态设定点存在差异。

还需要区分可预测的生理节律与情境驱动的生理变化。昼夜节律、月经周期等可能形成可预测节律；剧烈锻炼、感染、长时间禁食、饮酒、药物或补剂变化等则可能在特定情境中改变数值。它们都会影响观察结果，但不能全部混称为经典 biological variation 参数。例如，皮质醇常呈明显昼夜节律，因此不同采样时间可能产生显著差异。

**生物波动不是测量错误。** 它是被测生物系统本身的一部分，但仍需要结合具体指标、时间尺度和情境判断。

### 参考变化值 / Reference Change Value

Reference Change Value（RCV，参考变化值）可在具备可靠分析变异和个体内生物变异资料时，帮助判断两次结果差异是否超出预期变异。RCV 不是诊断阈值、个人目标、危急值或所有项目通用规则；本条不提供公式，也不据此进行个人计算。

## 3. 参考区间不等于个人基线

实验室报告的 reference interval 通常来自特定方法和参考人群，用于提供群体层面的比较背景。它与个人基线回答的问题不同：

- reference interval 说明某个实验室和方法下，参考人群结果的大致分布；
- personal baseline 说明某个用户在可比较条件下长期通常处于什么状态。

一个结果落在参考区间内，不代表它对每个人都理想；落在区间外，也不自动等于疾病诊断。临床 decision limit、风险相关阈值、critical/alert value 和未来个性化目标也都不能与 reference interval 混用。

用户实际结果应保留原实验室的原始参考区间，不应由 Registry 中的一个全球区间覆盖。

## 4. 方法、平台与单位变化是趋势断点

更换实验室、分析方法、设备型号、传感器位置、固件、算法版本或单位，可能改变结果的可比性。即使名称相同，数值也未必可以直接接在同一条趋势线上。

遇到断点时，应：

1. 保留每个结果的原始数值、单位、来源和方法；
2. 明确标记方法或平台变更日期；
3. 只在转换规则经过核验时进行单位转换；
4. 不对未知方法差异做自动归一化；
5. 必要时在专业指导下通过重叠测量建立可比性。

“数值看起来接近”并不能证明方法之间可互换。

## 5. 如何对待单次离群结果

单次离群结果首先是需要核对的信息，不是应被立即诊断或立即忽略的噪声。可以按顺序检查：

- 原始报告、项目名称、数值、单位和参考信息是否正确；
- 是否存在采集、样本、方法、设备或录入问题；
- 与既往可比结果相比，变化是否真实且幅度多大；
- 是否存在急性疾病、新的锻炼计划、饮食变化、药物或补剂的开始或停止、旅行或跨时区等相关上下文；
- 是否存在方法、平台、设备固件或算法版本变化；
- 报告是否标注 critical/alert，用户是否有急性或严重症状；
- 是否需要由实验室或专业人员判断复核、复测或进一步评估。

“先复核上下文”不等于延误紧急处置，也不等于自行制定复测时间表。

## 6. 最少上下文补全

当用户希望理解变化而现有信息不足时，Agent 应先复用已经授权的历史记录，再只补问与当前问题直接相关的缺口：

- 两次或多次结果的日期、数值和单位是什么？
- 来源的实验室、设备、方法、平台、固件或算法版本是否相同或可比？
- 采集条件是否可比，例如时间、禁食、运动或急性疾病背景？
- 原始报告的 reference interval、flag 或 critical/alert 标注是什么？
- 用户当前是否有需要及时处理的严重症状？

用户可以跳过任何问题。补问的目的只是识别可比性和安全边界，不是实施问诊、自动提醒、复测调度或个性化方案生成。

## 7. 与 Biomarker and Measurement Registry 的关系

本条解释测量变化的通用概念；Biomarker and Measurement Registry 为具体项目记录方法、单位、参考区间模型和可比性要求。二者互补，不互相替代。

## 8. 与 KN-T0204 的区别

`KN-T0204-0001` 回答 Congtie 如何通过“测量—解读—行动—复测”组织长寿实践反馈闭环。本条回答的是测量科学问题：为什么数值会变化，以及如何区分基线、趋势、测量误差和生物波动。

本条可以为反馈闭环的“测量”和“解读”提供基础，但不重复闭环的产品框架。本条本身不生成个人复测时间表；未来 Personalized Longevity Protocol 如包含复测安排，需要结合具体项目、方法、结果、风险、专业建议和安全治理。

## 9. Evidence Boundary

本条采用 `E3`，用于表达测量变异、可比性和 longitudinal interpretation 的一般基础。不同项目的生物变异、方法偏差、参考变化值和复测要求高度依赖具体 analyte、平台、人群和用途，不能从一般原则自动推导个人结论。

同行评议综述支持区分前分析、分析和生物变异；NIST 支持 error 与 uncertainty 的计量学区分；EFLM 资料支持按具体 analyte 使用 biological variation 与 RCV；MedlinePlus 支持实验室和方法差异、参考区间与检测前因素的一般教育。它们不支持跨平台自动归一化、个人诊断或固定复测频率。

## 10. Safety Boundary

Agent 不得：

- 把第一次结果自动设为个人基线；
- 把参考区间自动设为个人目标；
- 把短期波动等同于干预效果或疾病进展；
- 以“可能是误差或波动”为理由忽视 critical/alert 或严重症状；
- 未经核验跨方法、平台或单位合并趋势；
- 仅依据本条生成个人诊断、治疗、用药或个性化复测方案。

不得用“可能是波动”“存在方法差异”等一般原则，直接肯定或否定某项具体检测，也不得据此忽略异常。具体项目的准确性、可比性和复测需要独立核验。
