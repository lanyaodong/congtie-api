# Congtie 的长寿目标：延长健康寿命

## 1. One-line Summary

Congtie 的长寿目标是帮助用户延长健康寿命：不仅关注生命有多长，也关注长期能否保持能力、独立生活和较好的生活质量。

## 2. User-facing Explanation

在 Congtie 中，“延长健康寿命”同时表达用户希望获得的长期结果和 Congtie 的产品使命。这里的重点不是追求一个抽象的寿命数字，而是让更多生命年份尽可能伴随可用的身体与认知能力、行动能力、独立生活能力和生活质量。

这一目标与“无限寿命”不同。Congtie 不承诺让人永生，也不承诺逆转年龄。它也不把某个 biological age 数字当成长寿本身：单一估算指标可能提供有限背景，但不能代表一个人的全部功能、生活质量或未来寿命。

长寿目标之下可以有不同策略方向。Congtie 的 taxonomy 将“避免早逝、保持身体和认知能力、延缓生物衰老”放在 T02 长寿策略层。它们用于组织后续知识，不是本条目的详细行动方案，更不是针对个人的诊疗计划。

因此，Congtie v0 对长寿目标的支持主要是可信解释、背景组织、信息缺口识别和安全行动支持。目标提供方向，但不授权寿命预测、风险计算、临床建议或结果承诺。

## 3. Key Points

- 用户目标 / 结果：延长健康寿命。
- Congtie 使命：帮助用户延长健康寿命。
- 长寿目标关注功能、能力、独立生活和长期生活质量，不只是总年数。
- 避免早逝、保持能力和延缓生物衰老属于 T02 策略层，本条不展开。
- 长寿目标不等于无限寿命、逆龄承诺或追求单一 biological age 数字。
- Congtie v0 不预测寿命，不承诺结果，也不生成临床或个性化干预方案。

## 4. Evidence and Source Notes

1. `agent/knowledge_seed_v0/longevity_topic_taxonomy.v0.1.md` 明确记录“User goal / user result = extend healthspan”和“Congtie mission = help users extend healthspan”，并把目标与 T02 策略分开。
2. `agent/knowledge_seed_v0/longevity_information_library_architecture.v0.1.md` 将 Longevity Information Library 组织在帮助用户延长健康寿命的使命周围。
3. [WHO - Healthy ageing and functional ability](https://www.who.int/news-room/questions-and-answers/item/healthy-ageing-and-functional-ability) 支持功能能力、福祉以及做自己重视之事的公共卫生背景；它不定义 Congtie mission，也不支持个人寿命预测或逆龄承诺。

本条采用 `E5 / product_policy`。核心目标属于 Founder-reviewed 产品政策，而不是医学试验结论。WHO 来源只补充一般背景，不能把产品使命升级为 E1 或 E2 医学证据。

## 5. Safety Boundary

本条目不得用于：

- 承诺或预测个人寿命、健康寿命或衰老速度；
- 声称 Congtie 可以实现无限寿命或逆龄；
- 用单一 biological age 数字代表个人整体健康或未来；
- 生成疾病风险分数、身体系统评分、诊断或临床建议；
- 提供治疗、用药、剂量、补充剂或个性化干预方案。
